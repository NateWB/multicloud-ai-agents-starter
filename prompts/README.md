# Prompt pack

Tool-agnostic prompts. Each works in Claude Code, Gemini CLI, Codex, or Copilot, because the environment
and the rules live in `AGENTS.md`, not in the prompt.

| File | Goal |
| --- | --- |
| `01-add-spoke.md` | Add a second AWS spoke to the hub, with a plan and an approval gate |
| `02-diagnose-readonly.md` | Diagnose a connectivity problem with read-only commands |

To add one: goal, prompt text, expected output, and tested-in (tool and date).
